# Tags / References (docs hygiene)

This repo relies on consistent tags and citations.

## Tags

- If the docs enforce a tag registry, add new tags there before using them.
- Keep tag names stable and meaningful.

## References / bibliography

- Prefer adding a proper BibTeX entry over ad-hoc links.
- Keep citation keys unique.
- Ensure the docs build produces no duplicate-key warnings.

## Links

- Keep internal links stable.
- When renaming pages, update links in `wiki/` and `docs/`.
