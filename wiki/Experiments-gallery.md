# Experiments gallery

The experiments gallery is maintained in the **docs** site (Sphinx/MyST), not in the Wiki.

Use these entry points:

- Docs experiments directory (source): `docs/experiments/`
- Built HTML gallery: `docs/_build/html/experiments/` (after building docs)

Typical commands:

- Build docs: `make docs` (or `make docs-html` if your Makefile distinguishes targets)
- Validate docs: run the docs build in CI / your local workflow
- Update gallery assets (if applicable): follow the repo’s “gallery sync” tool scripts in `tools/`
