# E030 — Cousin and sexy prime pairs

<!-- REPORT:BEGIN -->
**Reproduce:**

```bash
make run EXP=e030
```

### Parameters
- n_max: `10000000`
- d_values: `[4, 6]`

### Notes
- Prime pairs with fixed even gap d are all instances of prime constellations.
- Different $d$ values have different 'local obstructions' (mod constraints) and different constants.
