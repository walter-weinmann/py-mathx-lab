# E033 — Bounded gaps vs twin primes (not the same)

**Reproduce:**

```bash
make run EXP=e033
```

## Parameters
- n_max: `10000000`
- threshold: `100`

## Notes
- Seeing many small gaps does not imply the smallest gap (2) occurs infinitely often.
- This is not a proof statement, just a numerical 'intuition guardrail'.
