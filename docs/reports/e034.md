# E034 — Twin primes in sliding windows

**Reproduce:**

```bash
make run EXP=e034
```

## Parameters
- n_max: `10000000`
- window: `500000`
- step: `200000`

## Notes
- Even if a heuristic gives an average density, local counts in windows vary a lot.
- This is a counterexample to 'smoothness' assumptions when eyeballing primes.
