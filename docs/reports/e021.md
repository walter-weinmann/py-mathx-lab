# E021 — Explicit bounds sanity checks

**Reproduce:**

```bash
make run EXP=e021
```

## Parameters
- n_max: `2000000`

## Notes
- Many explicit inequalities for $\pi(x)$ have *starting points* (valid only for $x ≥ x_0$).
- Experiments should always verify the assumptions before using a bound as a 'test oracle'.
