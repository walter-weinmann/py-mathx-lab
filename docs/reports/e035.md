# E035 — Primes in arithmetic progressions mod 12

**Reproduce:**

```bash
make run EXP=e035
```

## Parameters
- $n_max$: `10000000`
- $q$: `12`

## Notes
- Dirichlet's theorem guarantees infinitely many primes in each reduced residue class.
- Finite ranges show biases and slow convergence to equal proportions.
