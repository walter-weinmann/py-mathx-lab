# E044 — Solovay–Strassen vs Miller–Rabin (liars)

<!-- REPORT:BEGIN -->
**Reproduce:**

```bash
make run EXP=e044
```

### Parameters
- samples: `4000`
- bits: `32`
- bases: `[2, 3, 5, 7, 11]`

### Notes
- Both tests are probabilistic; liar rates depend on bases and on the composite distribution.
- In practice, Miller–Rabin with strong base sets is often preferred.
