# E040 — Palindromic primes and the '11 trap'

<!-- REPORT:BEGIN -->
**Reproduce:**

```bash
make run EXP=e040
```

### Parameters
- digits_max: `10`
- limit: `50000`

### Notes
- Every even-length base-10 palindrome is divisible by 11, hence composite (except 11 itself).
- Even-length palindromic primes found in this scan: `[11]`
