# E027 — Record prime gaps vs $\log^2$ heuristic

**Reproduce:**

```bash
make run EXP=e027
```

## Parameters
- n_max: `20000000`

## Notes
- Cramér-style heuristics suggest maximal gaps around $x$ scale like $O(\log^2 x$).
- This experiment is empirical: we compare record gaps to $\log(p)^2$ on a finite range.
