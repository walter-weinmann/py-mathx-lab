# E045 — Deterministic 64-bit MR base sets

<!-- REPORT:BEGIN -->
**Reproduce:**

```bash
make run EXP=e045
```

### Parameters
- samples: `20000`
- bits: `64`

### Notes
- For n < 2^64, the 12-base set (2..37 primes) is deterministic.
- Smaller base sets are faster but allow some composites through (rare, but real).
