# E007 — Mersenne number growth

**Reproduce:**

```bash
make run EXP=e007
```

## Parameters
- n_max: `500000`
- stride: `50`

## Quick reference table

| n | digits(M_n) | bits(M_n) |
|---:|---:|---:|
| 1 | 1 | 1 |
| 2 | 1 | 2 |
| 3 | 1 | 3 |
| 5 | 2 | 5 |
| 10 | 4 | 10 |
| 100 | 31 | 100 |
| 1000 | 302 | 1000 |
| 10000 | 3011 | 10000 |

## Notes
- For n ≥ 1, the bit-length of M_n is exactly n.
- digits(M_n) can be computed via floor(n·log10(2)) + 1 without building M_n.
