## Highlights

- Arranges integers on a **hexagonal lattice** using a ring-by-ring spiral enumeration.
- Highlights primes to reveal lattice-aligned structures.
- Parameterizable run: vary `--rings` from the command line (default: `150`).

## What is a hexagonal number spiral?

A **hexagonal number spiral** places integers on a hexagonal grid, starting at the center with $1$ and then enumerating concentric rings of size $6,12,18,\dots$. This provides an alternative to the square-lattice Ulam spiral and can emphasize different geometric patterns. citeturn2view0turn1view1

## Research question

Which geometric structures appear when primes are highlighted on a hexagonal spiral, and how stable are they as `rings` increases?

## Experiment design

- Enumerate a centered hex spiral for `rings` rings (total $1+3r(r+1)$ integers).
- Compute primes up to that total.
- Scatter-plot prime points on the hex grid (composites omitted).

## How to run

```bash
make run EXP=e126
make run EXP=e126 ARGS="--rings 250"
```

## Caveats

- Different conventions exist for hex-spiral enumeration; changing the rule can change the visible structures.
- This experiment plots primes only; adding composites can help visual comparisons.
