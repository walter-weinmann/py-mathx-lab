## Highlights

- A triangular “prime map” where row *m* contains the integers from $(m-1)^2+1$ to $m^2$.
- Prime-rich quadratic sequences show up as visually prominent **vertical streaks**.
- Parameterizable run: vary `--rows` from the command line (default: `301`).

## What is the Klauber triangle?

The **Klauber triangle** arranges the natural numbers into rows indexed by $m=1,2,3,\dots$ such that row $m$ contains the consecutive integers
$$(m-1)^2+1,\ (m-1)^2+2,\dots,\ m^2.$$
Each row therefore contains $2m-1$ entries. When primes are highlighted, surprising linear structures emerge. citeturn1view1turn1view0

## Research question

What prime-rich “streaks” are visible in the Klauber triangle at moderate sizes, and how do they change as `rows` increases?

## Experiment design

- Build the triangle up to `rows`, i.e. integers $1..rows^2$.
- Compute a prime mask up to $rows^2$.
- Render an image with primes highlighted and blank cells outside the triangle.

## How to run

```bash
make run EXP=e124
make run EXP=e124 ARGS="--rows 501"
```

## Recommended `rows` range

Runtime and memory scale roughly with `rows²` because about `rows²` integers are classified.

- **Minimum (still meaningful):** `rows = 101`
- **Default / recommended:** `rows = 301`
- **Comfortable upper range (typical laptop):** `rows = 801` or `1001`
- **Above ~`rows = 1501`:** expect noticeably higher runtime, depending on the prime-sieving implementation.

## Caveats

- This is a visualization experiment; visual streaks do **not** prove any conjecture about primes.
- Finite-size effects are strong: patterns can become clearer or disappear as `rows` changes.
