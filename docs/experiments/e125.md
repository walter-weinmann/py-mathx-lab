## Highlights

- Places integers on a spiral using polar coordinates $r=\sqrt{n}$ and $\theta = 2\pi\sqrt{n}$.
- Prime points often form a visually dense spiral with interruptions by composite numbers.
- Parameterizable run: vary `--n-max` from the command line (default: `250000`).

## What is the Sacks spiral?

In the **Sacks spiral**, each integer $n$ is mapped to polar coordinates
$$r_n = \sqrt{n},\qquad \theta_n = 2\pi\sqrt{n},$$
and plotted as $(x,y) = (r\cos\theta,\ r\sin\theta)$. Highlighting primes yields striking spiral fragments. citeturn1view1

## Research question

How does the visual “prime spiral density” change as `n_max` increases, and which structures persist across scales?

## Experiment design

- Compute primes up to `n_max`.
- Map prime integers to $(x,y)$ via the Sacks polar rule.
- Scatter-plot prime points (composites omitted).

## How to run

```bash
make run EXP=e125
make run EXP=e125 ARGS="--n-max 500000"
```

## Caveats

- Scatter plots are sensitive to marker size and resolution: the same data can look different depending on rendering.
- This is exploratory and qualitative; the plot suggests structure but does not quantify it.
